# هویت برند پارسا اپس — مرحله ۲ 🎨

این پوشه شامل هویت بصری جدید برای دو سطح برند است:

## ۱) برند اصلی: پارسا اپس (Parsa-Apps)

**ماموریت:** ساخت تجربه‌های دیجیتال خلاقانه — تلاقی آموزش، سرگرمی، فناوری و طراحی زیبا.

### کانسپت لوگو
- مونوگرام پرجزئیات و طلایی **PA** به‌عنوان نشان مرکزی
- نام دقیق **Parsa-Apps** با خط تیره، قاب‌ها و تزئینات طلایی
- در نسخهٔ متحرک، ده نویسه یکی‌یکی از سمت راست وارد می‌شوند و در جای نهایی قرار می‌گیرند
- پس‌زمینهٔ مشکی برای حفظ کنتراست، درخشش و حس پرمیوم نشان

### رنگ‌ها
- پس‌زمینهٔ اصلی: #030303
- طلایی روشن: #F9D87A
- طلایی گرم: #F0A12E
- نارنجی عمیق: #EF7A1A
- دارک رابط: #0F172A

### فایل‌های رسمی
- `parsa-apps-animated-logo.gif` → لوگوی اصلی و متحرک سایت
- `parsa-apps-animated-logo-poster.png` → فریم نهایی 909×886 برای چاپ و متادیتا
- `parsa-apps-animated-logo-poster-512.png` → نسخهٔ ثابت مربع برای PWA
- `parsa-apps-animated-logo-poster-192.png` → نسخهٔ ثابت کم‌حجم
- `../../tools/generate_animated_logo.py` → مولد قابل تکرار همهٔ خروجی‌ها از تصویر مرجع

### کاربرد
- لوگوی اصلی در هدر، هیرو، معرفی شخصی و فوتر همهٔ صفحات سایت
- نسخهٔ ثابت در حالت `prefers-reduced-motion`، متادیتای اشتراک‌گذاری و PWA
- فاوآیکون و آیکون نصب‌شوندهٔ سایت

## ۲) برند محصول: جزیره فندقی (Jazireh Fandoghi)

**ماموریت محصول:** دنیای کوچک، امن، شاد برای یادگیری، بازی و خیال‌پردازی کودکان ۳ تا ۹ سال.

### دو آیکون محصول
ما دو حالت آیکون ساختیم تا بسته به پلتفرم قابل استفاده باشد:

**A) آیکون کاراکتر فندقی (Mascot):**
- فندق بامزه با کلاه برگی، چشم‌های درشت براق، پاپیون آبی، فانوس در دست
- حس: صمیمی، مهربان، قابل اعتماد برای کودک
- فایل: `jazireh-fandoghi-app-icon-1024.png` → آیکون اپ iOS/Android (حالت پیشنهادی اصلی)
- سایزها: 512 , 192

**B) آیکون جزیره (Island):**
- جزیره شناور ساخته شده از نصف فندق، با خانه درختی چوبی، دو درخت، خزه و نورهای جادویی
- حس: ماجراجویی، خیال، کشف
- فایل: `jazireh-fandoghi-island-icon-1024.png` → `jazireh-island-512.png`
- استفاده: لوگوی داخل سایت، لودینگ اسکرین، اوپن‌گراف محصول

### رنگ‌های محصول
- پوست فندق: #8B4B1F → #E5A06A
- خزه / طبیعت: #2E9E5A → #7DDC9A
- آسمان غروب: #FFF6D6 → #BDEAFA → #8BCFE8
- چراغ خانه: #FFB347 / #FFD27A
- نور جادویی: #7EF2FF

### فایل‌ها محصول
- `jazireh-fandoghi-icon.svg` → آیکون جزیره وکتور ساده‌شده (برای سایت)
- `jazireh-fandoghi-logo.svg` → لوگوی افقی محصول با متن «جزیره فندقی»
- `jazireh-fandoghi-app-icon-*.png` → پک آیکون اپ
- `jazireh-island-*.png` → پک آیکون جزیره

## ۳) فاوآیکون و PWA

- `favicon.ico` → فاوآیکون چنداندازه بر پایهٔ فریم نهایی Parsa-Apps
- `assets/icons/icon-192.png` و `icon-512.png` → آیکون‌های مربع manifest
- `assets/icons/favicon-32.png` / `favicon-16.png` → fallback مرورگر
- `assets/brand/parsa-apps-animated-logo.gif` → لوگوی اصلی هدر و فوتر
- `assets/island-logo.jpg` → نشان محصول جزیره فندقی

## ۴) تصاویر شبکه‌های اجتماعی

- `assets/images/og-cover.jpg` → کاور اصلی OG 1200×630 (اتومات ریسایز از رندر جادویی)
- `assets/brand/social-og-1200x630.jpg` → نسخهٔ اصلی با کیفیت بالا
- `assets/brand/social-square-1080.jpg` → مربع 1080 برای اینستاگرام / تلگرام پروفایل
- `assets/images/social-share.jpg` → نسخه 1200×628 برای اشتراک‌گذاری
- `assets/images/mascot-fandoghi.jpg` → تصویر کاراکتر جدید (۶۰۰)
- `assets/images/island-mascot.jpg` → تصویر جزیره جدید (۶۰۰)

### رندر جادویی OG
ایده: جزیره شناور از جنس فندق، خانه درختی گرم با فانوس، کاراکتر فندقی با فانوس، آبشار کوچک، غروب طلایی، مه نرم. حس کلی: امن، گرم، جادویی، کودکانه اما پرمیوم.

- نام لاتین همیشه دقیقاً به شکل **Parsa-Apps** نوشته شود

- روی بک‌گراند تیره، از نسخه با هاله سفید استفاده شود (PNG فعلی هاله دارد)
