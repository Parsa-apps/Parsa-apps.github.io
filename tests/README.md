# تست‌های لایهٔ انیمیشن

اسکریپت `motion.test.js` رفتار موتور انیمیشن (`script.js`) را روی همهٔ صفحات
سایت با jsdom بررسی می‌کند: فعال‌شدن انیمیشن ورود، ساخت پس‌زمینه‌های متحرک،
احترام به `prefers-reduced-motion`، حالت Save-Data، دستگاه‌های ضعیف/لمسی،
حفظ کامل متن و ساختار صفحات، و سالم‌ماندن فرم تماس و منوی موبایل.

## اجرا

```bash
npm install jsdom      # پیش‌نیاز
node tests/motion.test.js
```
