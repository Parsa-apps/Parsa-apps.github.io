# دارایی‌های محصولات (سایت پارسا اپس)

این پوشه تصاویر **واقعی دو محصول** را نگه می‌دارد تا سایت با خود اپلیکیشن‌ها هم‌خوان بماند.

| پوشه | محصول | نسخهٔ مرجع | منبع تصاویر |
|---|---|---|---|
| `jazire/` | جزیره فندقی | `7.5.7+30` | مخزن [`Parsa-apps/Jazire-Fandoqi`](https://github.com/Parsa-apps/Jazire-Fandoqi) → `store/bazaar/upload/` و `assets/icon/` |
| `kartoniya/` | کارتونیا | `1.3.0+5` | مخزن [`Parsa-apps/Kartoniya`](https://github.com/Parsa-apps/Kartoniya) → `docs/screenshots/` و `asset/images/fandaq/` |

## ساختار هر پوشه

```
<app>/
├── full/            اسکرین‌شات کامل (حداکثر ۱۰۸۰ پیکسل عرض) — برای لایت‌باکس
├── sm/              بندانگشتی ۳۰۰px — برای نوار گالری
├── hero-*.webp      تصویر قاب گوشی در بخش معرفی محصول
├── card-740.webp    تصویر کارت پروژه (۷۴۰×۴۰۴)
├── icon-192.png     آیکون محصول (گالری و بخش معرفی)
└── icon-512.png     آیکون بزرگ
```

## قواعد به‌روزرسانی

1. تصاویر را از مخزن خود اپ بگیرید، نه از طرح‌های تبلیغاتی تولیدشده با هوش مصنوعی
   (فایل `store/myket/SCREENSHOTS_PLAN_FA.md` در مخزن جزیره فندقی هم صراحتاً
   استفاده از `promo/aurora` و `promo/generated` را برای فروشگاه منع می‌کند).
2. هر تصویر جدید باید هم در `full/` و هم در `sm/` با **همان نام فایل** ذخیره شود،
   چون گالری از `data-full` برای نسخهٔ بزرگ استفاده می‌کند.
3. بعد از آپدیت تصاویر، `CACHE_NAME` در `sw.js` را یک شماره بالا ببرید تا
   کش مرورگر کاربران تازه شود.
4. متن نسخه‌ها در `index.html` سه جا تکرار شده است: بخش محصول، کارت پروژه و
   داده‌های ساخت‌یافتهٔ JSON-LD — هر سه را با هم به‌روز کنید.
